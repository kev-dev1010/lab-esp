# Serial e Portas

Voltar para o [indice mestre](../index.md).

## Objetivo

Centralizar conhecimento recorrente sobre conexao serial, portas e comunicacao com ESP32.

## Este arquivo deve registrar

- portas usadas
- baud rates
- comandos de monitoramento
- problemas comuns de conexao
- padroes de validacao serial

## Perguntas que este arquivo deve responder

- qual porta usar em cada setup
- como confirmar que a placa foi reconhecida
- como abrir monitor serial
- como detectar conflito de porta ocupada
- que mensagens indicam sucesso ou falha
