# Problemas Conhecidos

Voltar para o [indice mestre](../index.md).

## Objetivo

Registrar problemas recorrentes de forma curta e reutilizavel.

## Estrutura sugerida

- sintoma
- causa
- como confirmar
- solucao
- links para logbook ou ADR quando existir

## Quando registrar aqui

- quando o mesmo problema pode reaparecer
- quando a solucao e curta o suficiente para consulta rapida
- quando o logbook ficou longo demais para ser fonte principal

## Quando deixar so no logbook

- quando for apenas uma tentativa sem conclusao
- quando ainda nao houver causa ou solucao confiavel
- quando o registro for importante so como historico bruto
