# Logbook

Voltar para o [indice mestre](../index.md).

## Objetivo desta pasta

Guardar o historico cronologico do projeto.

## Regra principal

O logbook nao deve ser carregado por padrao em toda sessao.

Ele existe para registro, auditoria e reconstrucao de contexto antigo quando necessario.

## Estrutura sugerida

- um arquivo por dia ou por bloco relevante de trabalho
- links para ADRs, issues, comandos e solucoes
- usar o [template de entrada](./entry-template.md) quando fizer sentido
